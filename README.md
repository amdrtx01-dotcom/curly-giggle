# DroneStrike - 3D Drone Combat Game

3D-игра про боевые дроны, созданная на Three.js. Управляй дроном, летай и уничтожай цели!

> **Бонус: `planes.html`** — отдельная 3D-игра про истребители Су-27, Су-24, Су-35, Су-57 и МиГ-29 с манёврами «Кобра Пугачёва», «Петля Нестерова», «Бочка», «Иммельман», «Чакра Фролова» и «Колокол». Без меню — сразу в полёт, процедурные текстуры 512×512, частицы (форсаж, выхлоп, контраилы). Открой `planes.html` в браузере или нажми на ссылку из локального http-server (см. ниже).

## Возможности

- **3D модели дронов** — детализированный квадрокоптер с вращающимися винтами, LED-индикаторами и системой вооружения
- **Красивое меню** — анимированное 3D-меню с вращающейся моделью дрона
- **Режим уровней** — 6 уровней с разными типами целей и окружением
- **Свободный полёт** — исследуй открытый мир без ограничений
- **Система оружия** — пулемёт и ракеты
- **HUD** — счёт, здоровье, топливо, высота, скорость, мини-карта
- **Эффекты** — взрывы, следы пуль, частицы двигателя

## Запуск

Откройте `index.html` в браузере. Игра использует Three.js из CDN.

Или запустите локальный сервер:
```bash
npx http-server . -p 8080
```

## Уровни

1. **Тренировка** — статические мишени в городе
2. **Конвой** — движущаяся техника в пустыне
3. **Оборона** — турели и техника на военной базе
4. **Воздушный бой** — вражеские дроны над океаном
5. **Полная зачистка** — все типы целей в горах
6. **Ночной рейд** — тайная операция в городе

## Технологии

- [Three.js](https://threejs.org/) — 3D рендеринг
- Vanilla JavaScript — игровая логика
- CSS3 — UI и анимации
